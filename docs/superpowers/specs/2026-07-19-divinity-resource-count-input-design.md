# Ручной ввод количества ресурсов божественности

## Цель

Добавить в каждую строку сундука и самоцвета блока «Мои ресурсы» компактный мобильный числовой ввод количества. Кнопки `−` и `+` удаляются: input становится единственным счётчиком и способом изменения отдельного значения.

## Строка ресурса

Строка сохраняет текущую структуру:

`[иконка и подпись уровня]     [input][действие]`

- Слева остаётся игровая иконка с подписью уровня под ней.
- После неё с заметным отступом располагается более широкий input фиксированной ширины, рассчитанной на `999`.
- Группа `[input][действие]` центрируется в оставшейся после левой иконки ширине строки.
- Между input и действием сохраняется фиксированный отступ; справа от input всегда зарезервирован фиксированный слот действия. Появление галочки или урны не меняет ширину строки и не сдвигает соседние элементы.
- Кнопки `−` и `+` и отдельный текстовый счётчик удаляются.
- На узких мобильных экранах строка не создаёт горизонтальный overflow.

## Ввод и ограничения

- Input показывает последнее сохранённое значение.
- Допустимы только цифры.
- `maxLength` равен трём символам, диапазон значения — `0…999`.
- Используются мобильные настройки цифрового ввода: `inputMode="numeric"` и `keyboardType="number-pad"`.
- Пустой черновик при подтверждении трактуется как `0`.
- Значения из прямого ввода и сохранённого состояния нормализуются в диапазон `0…999`.

## Черновик и подтверждение

- Редактирование input не меняет расчёт и сохранённые ресурсы до подтверждения.
- Если черновик отличается от сохранённого значения, в слоте действия отображается кнопка с галочкой.
- Галочка сохраняет нормализованное значение, обновляет расчёт и скрывается.
- Если пользователь вернул текст к сохранённому значению, галочка скрывается без записи.
- Сворачивание блока «Мои ресурсы» размонтирует строки и отбрасывает неподтверждённые черновики.

## Очистка

- После сохранения значения больше `0` в том же слоте действия отображается кнопка с SVG-иконкой урны.
- Урна сохраняет `0`, обновляет расчёт и синхронизирует input.
- При сохранённом `0` и неизменённом input слот остаётся пустым, но сохраняет размер.
- Если есть изменённый черновик, галочка имеет приоритет над урной.

## Данные и архитектура

- `CounterRow` отвечает только за локальный текстовый черновик и выбор видимого действия.
- `DivinityResourcesPanel` получает только прямые callbacks установки количества сундука и самоцвета и общий callback сброса.
- `useDivinityResources` предоставляет прямые setters с единым clamp `0…999`; устаревшие increment/decrement callbacks удаляются из UI-потока.
- Сохранение продолжает проходить через существующий `updateResources` и `saveDivinityResources`; формат AsyncStorage не меняется.
- Формула распределения сундуков и вычитания ресурсов не меняется.
- Иконка урны рисуется через уже установленный `react-native-svg`, без новой зависимости и без платформенного emoji.

## Доступность

- Каждый input получает понятное имя с типом и уровнем ресурса.
- Галочка имеет имя `Сохранить …`, урна — `Очистить …`.
- Подтверждение доступно касанием, мышью и клавиатурой.

## Единые шевроны

- Эталон формы — узкий символ `›`, уже используемый в карточках героев; обратная навигация сохраняет соответствующий `‹`.
- В сворачиваемых блоках и dropdown используется один символ `›` с поворотом: вниз в закрытом состоянии и вверх в открытом.
- Заменяются несовпадающие `▾` / `▴` в «Моих ресурсах», выборе героя в Builder и web-dropdown веток божественности.
- Уже корректные `‹` в шапках и `›` в карточках героев визуально не меняются.
- Размер контейнера шеврона остаётся фиксированным, поэтому раскрытие не сдвигает содержимое.

## Обновление инструкции

- Раздел «Мои ресурсы» объясняет, что количество вводится числом от `0` до `999` в поле рядом с иконкой ресурса.
- Неподтверждённый черновик не учитывается в расчёте.
- Галочка сохраняет новое значение и применяет его к расчёту.
- Урна очищает сохранённое значение и возвращает input к `0`.
- Описание `+` / `−` рядом с кругом божественности сохраняется без изменений: эти кнопки управляют прогрессом уровня и не относятся к «Моим ресурсам».

## Проверка

- Функциональные тесты input: фильтрация нецифровых символов, максимум `999`, черновик без влияния на расчёт, подтверждение, очистка, пустое значение как `0`.
- Проверка синхронизации после внешнего reset и сворачивания панели.
- Функциональная проверка одинакового символа dropdown-шевронов в трёх найденных местах; CSS-поворот тестами не проверяется и оценивается визуально на localhost.
- Проверка обновлённого пользовательского текста раздела «Мои ресурсы».
- TypeScript, полный Jest и web-export.
- В localhost при ширине `730 px` проверить мобильную клавиатурную конфигурацию в DOM, более широкий центрированный блок input/действия, устойчивую раскладку, отсутствие overflow, нормальную работу галочки и урны.

## Вне задачи

- Автосохранение при каждом введённом символе или при blur.
- Изменение расчёта расхода ресурсов.
- Изменение формы хранения ресурсов.
- Новые зависимости, commit или push без отдельной команды пользователя.
